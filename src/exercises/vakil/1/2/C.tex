EXERCISE. Show that $A \to S^{-1}A$ is injective if and only if $S$ contains no zerodivisors. (A zerodivisor of a ring $A$ is an element $a$ such that there is a nonzero element $b$ with $ab = 0$. The other elements of $A$ are called non-zerodivisors. For example, an invertible element is never a zerodivisor. Counterintuitively, $0$ is a zerodivisor in every ring but the $0$-ring. More generally, if $M$ is an $A$-module, then $a \in A$ is a zerodivisor for $M$ if there is a nonzero $m \in M$ with $am = 0$. The other elements of $A$ are called non-zerodivisors for $M$. Equivalently, and very usefully, $a \in A$ is a non-zerodivisor for $M$ if and only if $\times a : M \to M$ is an injection, or equivalently in the language of §1.5, if $0 \to M \xrightarrow{\times a} M$ is exact.)
